# Agent 虚拟工作区迁移本地真实文件系统——完整改造规划设计文档（可直接给 AI 执行开发）

## 1\. 项目背景与改造目标

当前 Agent 项目采用**内存虚拟 Workspace**，所有文件操作均在内存模拟，无法读写用户本地真实文件。

本次改造目标：

- **保留原有虚拟工作区逻辑、完全向后兼容**

- 新增 **本地真实文件系统模式**，支持 Agent 读写本机磁盘文件

- 实现**安全沙箱隔离**，杜绝路径逃逸、越权访问系统文件、误删风险

- 所有文件工具逻辑可在「虚拟模式 / 本地模式」一键切换

- 完整审计日志、风险拦截、异常防护

核心原则：**LLM 不可信任，所有路径、操作必须代码层强制校验，禁止让模型直接操作系统 API**。

## 2\. 整体架构改造方案（强制 AI 严格遵守）

### 2\.1 新旧架构对比

旧架构：Agent → 内存虚拟 Workspace

新架构：Agent → 文件工具中间层（校验\+沙箱）→ 本地真实文件系统

**关键：所有本地文件操作必须经过统一中间层，禁止绕过校验直接调用 fs / path 原生接口**

### 2\.2 核心模块拆分（必须实现）

1. 工作区模式管理器（虚拟 / 本地 切换）

2. 路径沙箱安全校验模块（核心安全层）

3. 本地文件工具集（对齐原有虚拟工具接口）

4. 高危操作拦截 \& 用户确认机制

5. 文件操作审计日志模块

6. 异常防护、大文件限制、并发安全模块

## 3\. 工作区模式配置规范

新增统一配置项，AI 必须读取该配置自动切换行为：

```Plain Text
{
  "workspace_mode": "virtual | local_fs",
  "sandbox_root": "本地可操作根目录",
  "allow_absolute_path": false,
  "allow_symbolic_link": false,
  "allow_dangerous_delete": false,
  "max_read_bytes": 2097152,
  "auto_confirm_high_risk": false,
  "enable_audit_log": true
}
```

规则：

- 默认保留 virtual 模式，保证旧功能完全可用

- local\_fs 模式下所有操作被沙箱严格限制

- 禁止 LLM 传入绝对路径，全部使用相对路径

## 4\. 沙箱路径安全规则（最高优先级，AI 必须严格实现）

### 4\.1 路径解析规则

- Agent 所有入参路径**强制相对路径**

- 工具层自动拼接 sandbox\_root 得到真实磁盘路径

- 所有路径必须规范化处理

- **必须检测路径逃逸：禁止 \.\./ 跳出沙箱根目录**

- **禁止跟随软链接**，防止链接跳转系统目录逃逸

### 4\.2 逃逸判定标准（必须代码实现）

真实解析后的路径，如果 **不严格以 sandbox\_root 为前缀** → 直接拒绝操作，返回权限错误。

特别注意：**不能直接使用 resolve\(\) 校验**，会被软链接绕过；必须先校验原始层级再解析。

## 5\. 文件工具接口规范（完全对齐原有虚拟工具）

所有工具**入参、返回结构完全复用旧虚拟工作区**，上层 Agent 逻辑无需改动。

仅底层实现切换为本地文件系统。

需要适配的工具列表：

- fs\_read\_file：读取文本文件，限制最大 2MB，拒绝二进制文件

- fs\_write\_file：写入/覆盖文件，覆盖属于高危操作

- fs\_list\_dir：列出目录，限制递归深度，防止卡死

- fs\_mkdir：创建目录

- fs\_rm：删除文件/文件夹（高危，默认拦截）

- fs\_cp：复制文件/目录（仅沙箱内）

- fs\_mv：移动/重命名（仅沙箱内）

- fs\_stat：获取文件信息

## 6\. 高危操作安全策略（强制实现）

以下操作标记为高危：

- 删除文件/目录 fs\_rm

- 覆盖已有文件

- 批量删除目录

策略：

- auto\_confirm\_high\_risk=false 时：**禁止自动执行，返回需要用户确认**

- 禁止删除沙箱根目录本身

- 禁止跨沙箱移动/复制文件到外部系统目录

## 7\. 审计日志设计

每一次本地文件操作必须落日志：

- 时间戳

- 工具名称

- Agent 传入相对路径

- 真实本地绝对路径

- 操作结果：成功 / 拦截 / 异常

- 错误信息（如有）

作用：可完整回溯 Agent 所有本地文件修改行为。

## 8\. 异常与边界防护（AI 必须全部处理）

- 超大文件保护：超过 max\_read\_bytes 直接拒绝读取

- 二进制文件检测，禁止读取进入 LLM 上下文

- 文件不存在、系统权限不足友好报错

- 目录遍历深度限制，防止海量文件遍历阻塞

- 文件读写并发安全，简单读写锁防冲突

- Windows / Linux / Mac 路径兼容处理

## 9\. 向后兼容要求（重要）

- 原有虚拟工作区代码**完全保留、不删除、不修改原有逻辑**

- 上层 Agent 调用工具代码**零改动**
